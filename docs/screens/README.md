# Every screen, as it actually renders

Regenerate with `pnpm shots` (see `scripts/shots.mjs`). These are committed so
that a change which moves something shows up in a diff rather than in a
complaint, and so anyone can review the product without installing PostgreSQL.

Two passes, each with a job:

- **`*-hi-phone.png`** — Hindi at 412px. The real product: what a teacher holds
  in one hand on a cheap Android. Judge usability on these.
- **`*-en-desktop.png`** — English at 1280px. What an officer or a funder sees
  in a slide. Never the primary.

Both are captured in `Asia/Kolkata` with an Indian browser locale, so dates read
the way they will on the device.

the images show is what the product does — not rows written straight into a
database. No screenshot contains a real child, because the platform holds none:
see [`../data-protection.md`](../data-protection.md).
